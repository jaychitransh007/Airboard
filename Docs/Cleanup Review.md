# Airboard cleanup review (12 November 2026)

Eight reviewers covered the whole repository, one area each:
- out-of-scope surfaces
- the board component
- the rest of the web app and its CSS
- the API
- the shared packages
- scripts, evals and CI
- docs
- dependencies and tooling

A second reviewer checked every finding against the code and corrected the recommended action where it was wrong. All 106 findings held up. I re-checked the most important ones myself.

Nothing has been changed. The appendix lists every finding with file paths, evidence, the proposed change and the checker's note.

**How to read the actions:**
- **Safe now:** nothing in the product or the build depends on it.
- **Your decision:** it removes something you said should stay for now, or it changes product scope.
- **Refactor:** it improves structure without changing behaviour.
